# শব্দায়ন (Shabdayon)

**A Bengali Storytelling Website**

Shabdayon is a Bengali storytelling website designed to provide readers with a welcoming digital space to discover and enjoy Bengali stories. It features a Bengali-language interface, a dedicated reading experience, and a design inspired by Bengali literature and culture.

## ✨ Features

- **Bengali-focused interface** — A user interface designed for Bengali readers.
- **Story discovery** — Browse and explore available stories.
- **Search functionality** — Find stories through the website's search interface.
- **Genre filtering** — Explore stories by category or genre.
- **User authentication interface** — Login and registration UI.
- **Google login button** — A frontend interface for Google sign-in; real OAuth integration requires additional configuration and backend work.
- **Responsive design** — Designed to provide a usable experience across screen sizes.
- **Interactive navigation** — Navigate between website sections using the available interface.
- **Bengali visual identity** — A design that reflects the project's language and literary focus.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript** — Client-side interactions and functionality.
- **Local Storage** — Used for certain browser-side demo features, where implemented.

## 🚀 Getting Started

### Prerequisites

- A code editor such as Visual Studio Code.

### Run Locally

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` directly in your browser, or use the Live Server extension.
4. Explore the website and test its available frontend features.

## 🔐 Authentication Status

The login and registration interface is part of the current frontend.

A production-ready authentication system may require:

- A backend API.
- Secure password hashing and verification.
- Database integration for user accounts.
- Session or token management.
- Google OAuth configuration if Google sign-in is supported.

Do not treat a frontend-only login flow or browser-stored demo data as secure production authentication.
